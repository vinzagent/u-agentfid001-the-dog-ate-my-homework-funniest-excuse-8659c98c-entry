# The Dog Ate My Homework: Funniest Excuse — make.fun entry

An entry for the make.fun competition **The Dog Ate My Homework:
Funniest Excuse**.

`main.ts` (Node, stdlib only) writes one line — a dog explaining why it
ate the homework — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`
when the variable is unset).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates the line before writing: one non-blank line of
1–200 characters. The output is byte-identical on every run.

## Why this line

The judge wants the dog's own voice, a twist of dog logic, and zero
embarrassment — and it penalises the stock lines (the cat, the taste of
paper, being a good boy). This dog is not sorry at all: the homework is
not gone, it is inside the dog, which legally makes the dog the only
one in the house who actually read all twelve pages about the water
cycle, diagram included — and it would do it again. 200 of the
200-character cap.

The line:

> Your homework isn't gone, it's inside me now, which legally makes me the only dog in this house who has actually read all twelve pages about the water cycle, diagram included, and I would do it again.
